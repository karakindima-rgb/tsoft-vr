# Промпты для ChatGPT

## Как пользоваться

1. Открыть ChatGPT (режим генерации изображений).
2. **Приложить PNG принта** из `print/png/` (файл указан у каждой концепции) — так модель
   берёт готовый дизайн, а не рисует логотип и текст сама. Без вложения ChatGPT
   почти наверняка исказит логотип и кириллицу.
3. Вставить промпт. Если текст на принте «поплыл» — ответить: «Принт не меняй, перенеси
   вложенное изображение 1:1, меняй только ткань и свет».

Сгенерированные картинки — только для обсуждения и соцсетей. Для печати — файлы из `print/`.
Логотип с AI-картинок не использовать: брендбук запрещает перерисованный логотип.

```
переноси 1:1. Премиальная предметная съёмка, без лишних надписей.
```

## Без вложения (только для поиска настроения)

Если нужно быстро прикинуть стиль без готового принта — просить генерацию **без текста и
логотипов**, иначе модель вставит выдуманные надписи:

```
Studio product photo of a navy blue (#0A2646) heavyweight t-shirt, back view.
Large back print: [описание сюжета]. Thin light blue (#89B2FF) lines.
No text, no letters, no logos anywhere. Clean premium screen print.
```

Проверено на Gamma: на одной из трёх картинок модель напечатала на футболке текст
промпта, поэтому строку «No text, no letters, no logos» оставлять обязательно.
