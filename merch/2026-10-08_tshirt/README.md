# Футболки Т-Софт

Три концепции в фирменном стиле (brand tokens v2.0, Inter, оригинальные файлы логотипа).
Мокапы: `mockup.html` и `preview/*.png`. Печатные файлы: `print/*.svg`.

| | A «Слоган» | B «Схема» | C «Журнал тренажёра» |
|---|---|---|---|
| Ткань | тёмно-синяя | тёмно-синяя | белая |
| Перед | логотип, 100 мм | знак, 55 мм | логотип, 100 мм |
| Спина | «Готовы до того, как случится», 280 мм | технологическая схема + «Модель, а не картинка», 280 × 324 мм | журнал учебного сценария, 280 × 190 мм |
| Цвета печати | белый, #89B2FF, #015AFD (знак) | #89B2FF, белый, #015AFD (знак) | #0A2646, #015AFD, #2B2A29 (логотип) |
| Для кого | заказчики, выставки | инженеры, команда | внутренний мерч, стажёры |

## Печатные файлы

- SVG в масштабе 1:1, единицы — мм, текст переведён в кривые.
- Логотип и знак вставлены из фирменных файлов без изменения геометрии и цвета.
- Цвета заданы в HEX. Подбор Pantone по HEX и пробный оттиск — на стороне типографии,
  утвердить до тиража: тёмно-синее полотно и краска на ткани дают сдвиг цвета.

## Размещение (размер L)

- Перед: левая сторона груди, верх принта ~7–8 см ниже горловины, центр ~9–10 см от центральной линии.
- Спина: по центру, верх принта ~6 см ниже горловины.
- Один размер принта для S–XXL. Для XS имеет смысл уменьшить спину до ~250 мм — уточнить у производителя.

## Технология (проверить у подрядчика)

- Тираж от ~50 шт., A и C — шелкография, 2–3 краски.
- B содержит тонкие линии (0,6–1,2 мм) и мелкий текст КИП (3,6 мм): для шелкографии
  нужна проверка подрядчиком на минимальную толщину; при сомнениях — DTF.
- Малые партии и пробники — DTF для всех вариантов.

## Риски

- На тёмной ткани знак логотипа печатается #015AFD — по брендбуку это допустимо только
  для крупной графики. На груди 100 мм знак ~26 мм, на оттиске проверить читаемость;
  запасной вариант — знак `tsoft-icon-white`.
- Фраза «Модель, а не картинка» взята из утверждённых ключевых сообщений; при этом
  конструкция «не X, а Y» в ToV помечена как маркер машинного текста. Решение — за маркетингом.

## Пересборка

```bash
pip install fonttools uharfbuzz
python3 src/build.py                          # print/*.svg и mockup.html
NODE_PATH=$(npm root -g) node src/render.cjs  # preview/*.png (Playwright)
```
