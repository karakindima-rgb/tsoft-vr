# Футболки Т-Софт

Пять концепций в фирменном стиле (brand tokens v2.0, Inter, оригинальные файлы логотипа).

- `2026-10-08_исследование-мерч.md` — тренды, источники, логика выбора.
- `mockup.html`, `preview/*.png` — мокапы перед/спина.
- `preview/ai/` — фотомокапы Gamma (только настроение, без логотипа и текста).
- `2026-10-08_промпты-chatgpt.md` — промпты для генерации фотомокапов в ChatGPT.
- `print/*.svg` — печатные файлы 1:1 (мм, текст в кривых); `print/png/` — те же в 300 dpi.

## Размещение (размер L)

- Перед: левая сторона груди, верх принта ~7–8 см ниже горловины, центр ~9–10 см от центральной линии.
- Спина: по центру, верх принта ~6 см ниже горловины; знак в концепции 5 — ~3 см ниже горловины.
- Один размер принта для S–XXL. Для XS уменьшить спину до ~250 мм — уточнить у производителя.

## Технология (проверить у подрядчика)

- Тираж от ~50 шт.: шелкография. Малые партии и пробники: DTF.
- 1: знак — вышивка; тональная краска на тон светлее полотна подбирается по пробнику
  (в макете #1A3A62, это технологический цвет, в палитру бренда не входит).
- 2 и 3: тонкие линии 0,45–1,2 мм, мелкий текст КИП 3,6 мм — подрядчик подтверждает
  минимальную толщину для шелкографии; при сомнениях — DTF.
- 5: персональные поля («Изделие», «Зав. №») — DTF; в `src/build.py` значения меняются
  в списке `rows` функции `s5_front`.
- Pantone по HEX подбирает типография; утверждать по пробному оттиску.

## Риски

- На тёмной ткани знак логотипа печатается #015AFD — по брендбуку допустимо только для
  крупной графики; проверить читаемость на оттиске (концепции 2 и 3), запасной вариант —
  белый знак.
- «Модель, а не картинка» (2) — утверждённое ключевое сообщение, но конструкция
  «не X, а Y» в ToV помечена как маркер машинного текста. Решение за маркетингом.
- Тональная краска (1) — не фирменный цвет; согласовать как технику печати.

## Пересборка

```bash
pip install fonttools uharfbuzz
python3 src/build.py                          # print/*.svg и mockup.html
NODE_PATH=$(npm root -g) node src/render.cjs  # preview/*.png и print/png/ (Playwright)
```
